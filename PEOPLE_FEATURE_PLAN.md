# План: Система управления "Люди" в приложении Starbucks Collection

## 📋 Архитектура базы данных

### Новые таблицы в Supabase:

#### 1. **people** — Информация о людях
```sql
CREATE TABLE people (
  id UUID PRIMARY KEY,
  name VARCHAR NOT NULL UNIQUE,
  location_from VARCHAR, -- Откуда человек (город/страна)
  avatar_image_path VARCHAR, -- Фото профиля
  bio TEXT, -- Описание человека
  is_visible BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 2. **person_contributions** — Контрибуции людей
```sql
CREATE TABLE person_contributions (
  id UUID PRIMARY KEY,
  person_id UUID FOREIGN KEY,
  country_id UUID FOREIGN KEY,
  mug_count INT, -- Сколько кружек привез из этой страны
  visited_date DATE, -- Когда посещал
  notes TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Изменения существующих таблиц:

#### **mugs** — Добавить связь с людьми
- Добавить: `brought_by_person_id` (UUID, FOREIGN KEY на people.id)

## 🎨 Компоненты, которые создадим

### 1. **PeopleGrid.jsx** — Красивая сетка карточек людей
- Карточки с фото профиля
- Имя, локация откуда привез
- Счётчик кружек
- Клик открывает детальное окно

### 2. **PersonDetail.jsx** — Детальное окно человека
- Фото профиля (большое)
- Имя и биография
- Список стран откуда привез кружки
- Галерея кружек от этого человека
- Локации на интерактивной карте

### 3. **PeopleAdmin.jsx** — Администрирование людей
- CRUD операции (создание, редактирование, удаление)
- Загрузка фото профиля
- Редактирование биографии
- Привязка кружек к людям

### 4. **PeopleVisualization.jsx** — Главная страница "Люди"
- Комбинирует PeopleGrid и фильтры
- Фильтр по доступным кружкам
- Поиск по имени
